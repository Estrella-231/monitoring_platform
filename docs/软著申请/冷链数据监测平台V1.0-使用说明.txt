第一章 软件说明
================================================================================

1.1 功能简介
-----------------------------------------------------------------
本软件采用B/S架构，实现冷链温湿度数据的实时采集、存储、
可视化展示和告警管理。支持多设备管理、灵活告警规则配置、
历史数据查询导出和统计分析报表功能。

1.2 软件特点
-----------------------------------------------------------------
1) 前后端分离架构，基于RESTful API通信
2) 支持硬件传感器和模拟数据两种采集模式
3) 实时数据可视化，提供多种图表展示
4) 灵活的告警规则配置，支持多条件组合
5) 完整的审计日志，记录所有操作

1.3 目标用户
-----------------------------------------------------------------
冷链物流企业、冷链仓储、药房、超市、农贸市场等需要
对温湿度进行实时监测的单位和场所。

第三章 安装说明
================================================================================

3.1 安装前检查
-----------------------------------------------------------------
确认计算机满足第二章所述的软硬件环境要求。

3.2 后端安装步骤
-----------------------------------------------------------------
步骤1：创建项目目录并进入
```bash
mkdir cold-chain-monitoring
cd cold-chain-monitoring
```

步骤2：创建Python虚拟环境
```bash
python3 -m venv .venv
```

步骤3：激活虚拟环境
```bash
# Linux/macOS:
source .venv/bin/activate

# Windows:
.venv\Scripts\activate.bat
```

步骤4：安装后端依赖
```bash
pip install -r requirements.txt
```

步骤5：配置环境变量（可选）
```bash
cp .env.example .env
# 根据需要修改配置文件
```

3.3 前端安装步骤
-----------------------------------------------------------------
步骤1：进入前端目录
```bash
cd frontend
```

步骤2：安装前端依赖
```bash
npm install
```

步骤3：返回上级目录
```bash
cd ..
```

第四章 启动说明
================================================================================

4.1 启动后端服务
-----------------------------------------------------------------
步骤1：激活虚拟环境
```bash
source .venv/bin/activate   # Linux/macOS
.venv\Scripts\activate.bat # Windows
```

步骤2：启动后端服务
```bash
python3 backend/main.py
```

步骤3：验证启动成功
后端服务启动后，访问 http://localhost:8000/docs 查看自动生成的API文档。

4.2 启动前端服务
-----------------------------------------------------------------
步骤1：进入前端目录
```bash
cd frontend
```

步骤2：启动开发服务器
```bash
npm run dev
```

步骤3：访问Web界面
打开浏览器访问 http://localhost:5173

4.3 启动数据采集端（可选）
-----------------------------------------------------------------
步骤1：激活虚拟环境
```bash
source .venv/bin/activate
```

步骤2：启动采集端
```bash
python3 sensor/collector.py
```

说明：
- 默认使用mock模式生成模拟数据
- 启动后会自动每10秒生成一条模拟数据上报到后端
- 如需连接真实传感器，请修改sensor/collector.py中的配置

第五章 操作使用说明
================================================================================

5.1 首次登录操作
-----------------------------------------------------------------
1) 打开浏览器访问 http://localhost:5173
2) 点击"注册"按钮进入注册页面
3) 输入用户名、密码、电子邮箱
4) 点击"注册"完成账号创建
5) 使用注册的账号密码登录系统

5.2 仪表盘操作（DashboardPage）
-----------------------------------------------------------------
功能：实时查看监测数据

操作说明：
- 登录成功后自动进入仪表盘页面
- 页面显示内容：
  * 设备总数统计
  * 在线设备数量
  * 温度实时趋势图
  * 湿度实时趋势图
  * 告警数量统计
  * 设备状态分布饼图
- 数据每5秒自动刷新
- 可切换查看24小时/7天/30天的历史趋势

5.3 设备管理操作��DevicesPage）
-----------------------------------------------------------------
功能：管理监测设备

操作说明：
- 查看设备列表：页面显示所有已注册设备
- 添加设备：点击"添加设备"按钮，填写设备名称、设备位置等信息
- 编辑设备：点击设备行的编辑图标进行修改
- 删除设备：点击设备行的删除图标（需二次确认）

5.4 告警规则配置操作（AlertRulesPage）
-----------------------------------------------------------------
功能：配置温度/湿度告警规则

操作说明：
- 查看规则列表：页面显示所有已配置的告警规则
- 添加规则：点击"添加规则"按钮
  * 选择监测指标（温度或湿度）
  * 选择条件（大于、小于、等于、大于等于、小于等于）
  * 设置阈值（如：温度>30℃）
  * 设置告警启用/禁用状态
- 编辑规则：点击规则行的编辑图标
- 删除规则：点击规则行的删除图标
- 告警触发：当数据满足规则条件时自动产生告警

5.5 历史数据查询操作（HistoryPage）
-----------------------------------------------------------------
功能：查询历史监测数据

操作说明：
- 输入时间范围（开始时间、结束时间）
- 选择设备（可选，不选则查询所有设备）
- 点击"查询"按钮
- 查看数据列表
- 支持导出CSV格式

5.6 报表导出操作（ReportsPage）
-----------------------------------------------------------------
功能：生成统计报表

操作说明：
- 选择报表类型（日报/周报/月报）
- 选择时间范围
- 点击"生成报表"
- 查看报表数据内容
- 支持下载报表文件

5.7 审计日志操作（AuditLogsPage）
-----------------------------------------------------------------
功能：查看操作审计记录

操作说明：
- 页面显示所有操作记录
- 每条记录包含：操作人、操作时间、操作类型、操作内容
- 支持按时间范围筛选

5.8 通知中心操作（NotificationsPage）
-----------------------------------------------------------------
功能：查看系统通知和告警通知

操作说明：
- 页面显示所有通知消息
- 可点击标记为已读
- 可删除通知消息

5.9 系统设置操作（SettingsPage）
-----------------------------------------------------------------
功能：系统配置和个人设置

操作说明：
- 修改个人信息（头像、昵称）
- 修改登录密码
- 配置数据刷新间隔
- 配置通知渠道

第六章 使用场景示例
================================================================================

场景一：实时温度监控
-----------------------------------------------------------------
1) 启动后端服务和前端服务
2) 启动数据采集端（mock模式）
3) 打开浏览器访问 http://localhost:5173
4) 登录系统后自动进入仪表盘
5) 查看实时温度、湿度数据
6) 观察温度/湿度趋势图变化

场景二：配置温度告警
-----------------------------------------------------------------
1) 登录系统后进入"告警规则"页面
2) 点击"添加规则"按钮
3) 选择"监测指标"为"温度"
4) 选择"条件"为"大于"
5) 设置"阈值"为"30"（摄氏度）
6) 确保"启用"开关打开
7) 点击"保存"按钮
8) 当采集的温度超过30℃时，系统自动产生告警

场景三：导出历史数据报表
-----------------------------------------------------------------
1) 登录系统后进入"历史数据"页面
2) 选择时间范围（如：2026-04-01 至 2026-04-30）
3) 可选择指定设备（可选）
4) 点击"查询"按钮
5) 点击"导出CSV"按钮
6) 下载CSV文件到本地

场景四：多设备管理
-----------------------------------------------------------------
1) 登录系统后进入"设备管理"页面
2) 点击"添加设备"按钮
3) 填写设备名称（如：冷藏库A）
4) 填写设备位置（如：仓库1号）
5) 点击"保存"完成设备添加
6) 在数据采集端配置设备ID，采集端即可向上报数据

第七章 故障排除
================================================================================

7.1 后端无法启动
-----------------------------------------------------------------
可能原因1：虚拟环境未激活
  解决：执行 source .venv/bin/activate 激活虚拟环境

可能原因2：端口8000被占用
  解决：更换端口或关闭占用进程（lsof -i:8000）

可能原因3：依赖未安装完整
  解决：执行 pip install -r requirements.txt 重新安装

7.2 前端无法访问
-----------------------------------------------------------------
可能原因1：端口5173被占用
  解决：更换端口或关闭占用进程

可能原因2：npm依赖缺失
  解决：执行 npm install 重新安装

可能原因3：Node.js版本过低
  解决：升级Node.js到18+

7.3 数据未显示
-----------------------------------------------------------------
可能原因1：后端服务未运行
  解决：检查后端服务是否正常启动

可能原因2：采集端未启动
  解决：启动数据采集端 python3 sensor/collector.py

可能原因3：API地址配置错误
  解决：检查采集端配置文件中的API地址

7.4 告警未触发
-----------------------------------------------------------------
可能原因1：告警规则未启用
  解决：在告警规则页面确认规则启用

可能原因2：阈值设置不当
  解决：调整阈值使其符合当前数据范围

可能原因3：数据未超过阈值
  解决：检查当前数据是否满足告警条件
