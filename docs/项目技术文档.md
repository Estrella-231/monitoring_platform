# 冷链数据监测平台 — 软著技术文档

> Cold Chain Control Tower · 冷链运输态势感知系统
> 用途：中国计算机软件著作权登记

---

## 一、项目概述

冷链数据监测平台是一个面向冷链物流场景的温湿度监测与告警系统。支持多传感器设备接入、实时数据采集、阈值告警触发、历史趋势分析、数据报表导出、审计日志追溯、用户权限管理等功能模块。

### 核心能力

- 多设备传感器数据实时采集与展示
- 自定义温湿度阈值告警规则
- 设备 CRUD 管理与状态监控
- 历史数据查询与 CSV 导出
- 日报/周报聚合统计
- 操作审计日志全量记录
- 通知渠道灵活配置
- JWT 用户认证与角色权限

```

│                    Frontend (React)                   │

│            dev: localhost:5173                        │
└──────────────────────┬──────────────────────────────┘

                       ▼
┌──────────────────────────────────────────────────────┐

│  models.py    stores.py    auth.py    services.py      │

```

### 技术栈

| 层次 | 技术 | 说明 |
|------|------|------|
| 前端框架 | React 18 + TypeScript | Vite 构建 |
| 状态/请求 | @tanstack/react-query | 自动轮询 + 缓存刷新 |
| 路由 | react-router-dom v6 | 嵌套路由 + 鉴权守卫 |
| 图表 | 纯 SVG 手绘 | 无第三方图表库依赖 |
| 后端框架 | FastAPI (Python 3.11) | RESTful JSON API |
| 认证 | JWT (python-jose) + bcrypt | 72h 过期, 角色控制 |
| 数据存储 | Python 内存列表 | 重启即清空 (软著演示) |
| 传感器 | DHT11 (RPi) / Mock 模式 | 正弦波模拟数据 |

## 六、启动方式

```bash
source .venv/bin/activate

# 监听 http://localhost:8000
```


## 八、认证机制

- JWT (JSON Web Token)，`python-jose[cryptography]` 签发验证
- 密码使用 `passlib[bcrypt]` (bcrypt 4.0.1) 哈希存储
- Token 有效期 72 小时
- 默认管理员账号：`admin / admin123`
- 角色：`admin` (全部权限)、`viewer` (只读)

## 十、注意事项

1. **数据持久性**：存储采用 Python 内存列表，服务重启后数据丢失。后续可接入 PostgreSQL + TimescaleDB 实现持久化。
2. **安全性**：当前为演示原型，未实现 HTTPS、速率限制、设备签名等生产级安全措施。
3. **传感器**：`sensor/collector.py` 支持 DHT11 硬件采集和 Mock 模拟两种模式，默认 Mock。
4. **Python 版本**：需 Python 3.11+，依赖 `bcrypt < 4.1` (与 passlib 兼容性约束)。
